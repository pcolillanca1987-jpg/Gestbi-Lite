# GESTBI MATCH - Gran Concepción (Versión Producción)

Sistema de gestión y match de piezas y habitaciones para todo público en el Gran Concepción (Centro, Collao, Nonguén, San Pedro, Talcahuano, Coronel, etc.).

## Estructura
- **Base de Datos 1:** Propiedades (Habitaciones, fotos, sectores, servicios).
- **Base de Datos 2:** Postulantes (Requisitos, presupuesto, perfil, contacto).
- **Almacenamiento:** Carga de hasta 5 imágenes por pieza con exportación/sincronización a OneDrive Empresa.
